# 4 — Real-world Retail Data Project
End-to-end mini project for retail sales: prepare data, analyze sales/profit by product and region, visualize trends, and estimate order sales with a Random Forest model compared to a mean baseline.
Run `task_1_prepare_data.py`, `task_2_sales_analysis.py`, and `task_3_sales_prediction.py` in order.
The included data is synthetic, not company data. Use an authorized real dataset and validate model performance before drawing business conclusions.
